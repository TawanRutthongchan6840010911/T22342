# AEGIS — Personal Protection

เว็บบริษัทร่างแรกสำหรับโครงงาน Startup Landing Page โทนดำ–ส้ม ใช้ HTML, CSS, JavaScript และ Bootstrap 5.3.3 เก็บไฟล์ Bootstrap และฟอนต์ไทยไว้ในโปรเจกต์ เปิดในเครื่องหรือ GitHub Pages ได้โดยไม่ต้องติดตั้งแพ็กเกจหรือ build

## เปิดดู

ดับเบิลคลิก `index.html` เพื่อเปิดด้วยเบราว์เซอร์ หรือเปิดโฟลเดอร์นี้ด้วย VS Code แล้วใช้ Live Server

ถ้ามี Python: รัน `python -m http.server 4173` ในโฟลเดอร์นี้ แล้วเปิด `http://localhost:4173`

## เผยแพร่บน GitHub Pages

1. สร้าง repository บน GitHub เช่น `aegis-bodyguard` (บัญชี GitHub Free ใช้ repository แบบ Public)
2. อัปโหลด `index.html`, `guards.html`, `about.html`, โฟลเดอร์ `members`, `assets` และไฟล์ `.nojekyll` ไว้ที่ระดับบนสุดของ repository ไม่ใส่ทั้งหมดไว้ในโฟลเดอร์ซ้อนอีกชั้น
3. ไปที่ **Settings → Pages → Build and deployment → Source: Deploy from a branch**
4. เลือก branch `main` และโฟลเดอร์ `/(root)` แล้ว Save
5. รอการเผยแพร่สำเร็จ แล้วเปิด URL ที่ GitHub แสดง เช่น `https://YOUR-USERNAME.github.io/aegis-bodyguard/`
6. ทดสอบเมนู หน้า About, Resume, ตัวกรอง และภาพบน URL จริงก่อนส่ง

ไม่ต้องอัปโหลดโฟลเดอร์ `tmp`, `output` หรือไฟล์ ZIP และไม่ต้องมี Node.js บน GitHub Pages

คู่มือทางการ: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

## เติมข้อมูลภายหลัง

โค้ด HTML, CSS และ JavaScript ที่เขียนสำหรับเว็บนี้จัดย่อหน้า 2 ช่อง พร้อมคอมเมนต์ภาษาไทยแบ่งส่วนแล้ว สามารถแก้ไฟล์ HTML ได้โดยตรง ไม่ต้องรันตัวสร้างหน้าในโฟลเดอร์ `tmp`

ถ้าใช้ VS Code กับส่วนเสริม Prettier ให้กด **Shift + Alt + F** เพื่อจัดรูปแบบ ไฟล์ `.prettierrc.json` และ `.editorconfig` ช่วยคงรูปแบบเดียวกัน ส่วน `assets/vendor` เป็นไลบรารี Bootstrap สำเร็จรูปแบบย่อ ไม่ใช่โค้ดที่ต้องแก้เพื่อปรับเว็บ

- เปลี่ยนชื่อแบรนด์และประวัติบริษัทใน HTML
- ใส่รูป ชื่อ นามสกุล และหน้าที่จริงของสมาชิกใน `about.html`; ลดหรือเพิ่มการ์ดให้ตรงจำนวนสมาชิก
- เปลี่ยนลิงก์ Resume ใน `about.html` ให้เป็น GitHub Pages ของสมาชิกแต่ละคน โครง Resume ใน `members` เป็นหน้าสำรองสำหรับร่างเท่านั้น
- แทนกล่อง `.portrait` ด้วย `<img>` เมื่อมีรูป พร้อมใส่ `alt` ให้เหมาะสม
- เติมชื่อและรายละเอียดบอดี้การ์ดในหน้าแรกและหน้า `guards.html` ให้ตรงกับ `assets/js/data.js`
- เติมราคาและเงื่อนไขในส่วน `#pricing`; ปัจจุบันจงใจเว้นราคาไว้ตามคำขอ
- แก้ Social links ของบริษัทใน footer ของทุกหน้า; ตอนนี้ใช้ลิงก์ตัวอย่างและเว็บไซต์ PIM ตามที่เกณฑ์อนุญาต
- ปุ่มดาวน์โหลดเปิดไฟล์แนะนำบริการฉบับร่าง `assets/downloads/aegis-overview.txt`; ยังไม่มีแอปจริง

## ขอบเขตฉบับร่าง

ใต้หัวข้อ **YOUR WORLD. OUR WATCH.** มีวิดีโอหลุมดำชิดขอบซ้าย ไล่ขอบจางเข้ากับพื้นหลัง เล่นวนอัตโนมัติแบบไม่มีเสียง และมีปุ่มหยุด–เล่นขนาดเล็ก วิดีโอหยุดเมื่อเลื่อนพ้น Hero หรือเปลี่ยนแท็บ และเริ่มเป็นภาพนิ่งเมื่อผู้ชมตั้งค่าลดการเคลื่อนไหว ไฟล์อยู่ในโปรเจกต์และใช้บน GitHub Pages ได้

เพิ่มตัวอย่างขยายฟีเจอร์ **เลือกคนที่ใช่** ใต้สรุปจุดเด่น 3 ช่อง เปิดหน้าแรกแล้วเลื่อนลง หรือกด **สำรวจการเลือกผู้ดูแล** เพื่อทดลอง โน้ตบุ๊กจะเริ่มจากพับ หมุนและกางตามระยะเลื่อนจนแสดงชื่อฟีเจอร์บนจอ เลื่อนย้อนแล้วพับกลับได้

ฟีเจอร์ที่สอง **ดูแลตามแผนของคุณ** อยู่ถัดจากฉากโน้ตบุ๊ก กด **สำรวจแผนการดูแล** หรือเลื่อนลงตามหน้า ตัวละครชุดขาวจะเลื่อนเข้าจากขวาพร้อมมือโชว์เพชร และ GIF จะค่อย ๆ ชัดขึ้นแล้วเล่นวน มีปุ่มปิด–เปิดพื้นหลังเคลื่อนไหว GIF โหลดเฉพาะเมื่อใกล้ฉากและหยุดเมื่อพ้นฉากหรือเปลี่ยนแท็บ มือถือจัดข้อความไว้ด้านบนและตัวละครด้านล่าง

กรณีลดการเคลื่อนไหวจะแสดงตัวละครนิ่งและไม่โหลด GIF

ฟีเจอร์ที่สาม **ความเป็นส่วนตัวมาก่อน** มีช่วงขยายถัดจากฉากที่สอง กด **สำรวจความเป็นส่วนตัว** เพื่อเข้าฉาก หัวข้ออยู่ฝั่งขวา ส่วน Albert เข้าจากซ้าย แล้วเปลี่ยนภาพนิ่ง 3 ท่าด้วย crossfade ตามระยะเลื่อน: หันข้าง → จับแว่น → เลื่อนแว่นลง พื้นหลัง GIF จางเข้ามาเล่นวนและปิดได้ หน้าเว็บไม่โหลด GIF Albert ขนาด 19 MB แต่ใช้ภาพ WebP ที่แยกออกมาแทน

โมเดลทำด้วย HTML/CSS 3D และ JavaScript ไม่ต้องติดตั้งไลบรารีเพิ่มและใช้บน GitHub Pages ได้ มีลิงก์ข้ามไปดูโปรไฟล์และแสดงเครื่องกางแล้วเป็นภาพนิ่งเมื่อผู้ใช้ตั้งค่าลดการเคลื่อนไหวหรือปิด JavaScript

แนวทางการนำเสนออ้างอิงจากหน้า ROG ที่ผู้ใช้ให้: https://rog.asus.com/th/laptops/rog-strix/rog-strix-scar-18-2026/ โดยสร้างรูปทรงและกราฟิก AEGIS ขึ้นในโค้ดของเว็บนี้

ข้อมูลสมาชิก รูปโปรไฟล์ ประวัติ ราคา และช่องทางบริษัทเป็นช่องรอเติม ไม่ใช่ข้อมูลบุคคลหรือบริษัทจริง แบบฟอร์มแสดงสรุปบนหน้าจอเท่านั้น ไม่ส่ง ไม่บันทึกข้อมูล และไม่ยืนยันการจอง ไม่มีระบบชำระเงินหรือระบบหลังบ้าน

ยังไม่ได้เผยแพร่ไปยังบัญชี GitHub ของผู้ใช้ และยังไม่ใช่งานพร้อมส่งจนกว่าจะเติมรายการใน checklist
