# ภาพนิ่งจาก albert.gif

แยกจาก GIF ต้นฉบับที่ผู้ใช้ส่งมาโดยตรง ไม่สร้างท่าทางหรือใบหน้าใหม่

GIF ต้นฉบับ: 600 × 568 พิกเซล, 117 เฟรม, ความยาวรวมประมาณ 3.56 วินาที

| ลำดับ | เฟรมต้นฉบับ (เริ่มที่ 0) | เวลาโดยประมาณ | ท่า | ภาพสำหรับเว็บ |
|---|---:|---:|---|---|
| 1 | 0 | 0.00 วินาที | หันข้าง | `assets/images/privacy/albert-01.webp` |
| 2 | 40 | 1.21 วินาที | ยกมือจับแว่น | `assets/images/privacy/albert-02.webp` |
| 3 | 71 | 2.15 วินาที | เลื่อนแว่นลง | `assets/images/privacy/albert-03.webp` |

ภาพ PNG ขนาดต้นฉบับแยกไว้ใน `output/albert-stills/` และรวมไว้ใน `output/albert-stills.zip`

หน้าเว็บแสดงภาพแบบเลื่อนเข้าจากซ้าย แล้ว crossfade ภาพ 1 → 2 → 3 ตามระยะเลื่อน ส่วนพื้นหลังใช้ GIF อีกไฟล์ที่ผู้ใช้ให้มา (`assets/media/privacy-background.gif`) ซึ่งตั้งค่า loop=0 หรือเล่นวนอยู่แล้ว

การจัดสีและขอบภาพทำผ่าน CSS เพื่อกลืนกับฉากโทนม่วงดำ ไฟล์ PNG ที่ส่งออกเก็บสีและรายละเอียดเดิมไว้
