- แทรก #reviews ระหว่าง #bodyguards กับ #pricing ตรวจลำดับจาก DOM แล้วถูกต้อง

## วิดีโอหลุมดำใน Hero — 31 ตุลาคม 2026

- ใช้ไฟล์ MP4 ของผู้ใช้ ความละเอียด 1920 × 1080 ความยาว 15 วินาที ขนาดประมาณ 8.3 MB
- ตรวจใน Chrome แยกสำหรับทดสอบ: วิดีโอโหลดพร้อมเล่น (readyState 4), เวลาเดินจริง, ปิดเสียง และเล่นต่อเมื่อจบไฟล์ได้
- Desktop 1440 × 1000: อยู่ใต้หัวข้อด้านซ้ายและไล่ขอบจาง ภาพมี opacity 0.42
- Mobile 390 × 844 และ 320 × 844: วิดีโอชิดซ้ายที่ตำแหน่ง 0px, opacity 0.34 และไม่ล้นแนวนอน
- ปุ่มหยุด–เล่นทำงาน วิดีโอหยุดเมื่อ Hero พ้นหน้าจอ และเล่นต่อเมื่อกลับมา
- จำลอง prefers-reduced-motion ในเบราว์เซอร์ทดสอบแล้ววิดีโอหยุด โดยไม่ได้เปลี่ยนการตั้งค่าระบบผู้ใช้
- ไม่พบ JavaScript exception; โค้ดผ่านการตรวจ syntax และรูปแบบ ลิงก์ไฟล์และ anchor ใน HTML ทั้ง 9 หน้าถูกต้อง
- ภาพตรวจอยู่ที่ output/hero-black-hole-desktop.png และ output/hero-black-hole-mobile.png

- เว็บใช้ WebP รวมประมาณ 195 KB แทนการโหลด albert.gif ขนาดประมาณ 19 MB
- Desktop 1440 × 1000: หัวข้ออยู่ฝั่งขวา ภาพอยู่ฝั่งซ้าย และ GIF พื้นหลังเล่นวน

- Mobile 390 × 844: ภาพที่ 3 แสดงได้ที่ระยะ 0.779 โดยอยู่ใต้ข้อความ; ความกว้าง 320 และ 390px ไม่พบเนื้อหาล้นแนวนอน
- ปุ่มปิดพื้นหลังซ่อน GIF และถอด src; ปุ่มเปิดกลับโหลดไฟล์และแสดงใหม่ได้
- ไม่พบ console error ในรอบตรวจมือถือ และโค้ดผ่านการตรวจ syntax/รูปแบบ
- ไฟล์ PNG ต้นฉบับสำหรับดาวน์โหลดอยู่ใน output/albert-stills.zip ส่วนไฟล์ที่ใช้จริงในเว็บอยู่ใน assets/images/privacy


## ฟีเจอร์ที่สอง: ตัวละครถือเพชรและ GIF พื้นหลัง

- Mobile 390 × 844: ข้อความและลิงก์อยู่ด้านบน ตัวละครเต็มตัวอยู่ด้านล่างโดยไม่บังข้อความ
