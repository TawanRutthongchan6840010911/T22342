คำขอเพิ่มเติมล่าสุด: ทำเป็นกล่องร่างเท่ ๆ และยังไม่ใส่รายละเอียดมาก จึงเตรียมโครงครบและเว้นข้อมูลจริงไว้ ไม่ถือว่าช่องรอเติมผ่านเกณฑ์เนื้อหาเต็มแล้ว

## การตีความ Responsive

เอกสารใช้คำว่า row บางจุด แต่ภาพตัวอย่าง Features เป็น 3 คอลัมน์แนวนอน และหน้าแรกระบุชัดว่า 3 column จึงจัดการ์ดเป็นคอลัมน์ตามภาพ: Features = 3/1/1 และ Members = 3/2/1 สำหรับ desktop/tablet/mobile ตามลำดับ

Header จัดข้อความและภาพข้างกันบน desktop และเรียงแนวตั้งในพื้นที่เดียวบน tablet/mobile ตามตัวอย่างของเอกสาร คำว่า “2 row” ในเกณฑ์ไม่สอดคล้องกับคำเรียก layout จึงใช้ตัวอย่างภาพเป็นหลัก; หากผู้สอนตั้งใจหมายถึงสองแถวจริง ให้ยืนยันก่อนส่ง

ไม่มี Testimonial เพราะเกณฑ์ให้เลือก Additional section อย่างน้อยหนึ่งประเภท และไม่ต้องการสร้างคำรับรองที่ไม่มีผู้ใช้งานจริง

## งานนอกเว็บไซต์ที่ยังต้องทำก่อนส่ง

เพิ่มฉากขยายครบ 3 หัวข้อแล้ว: โน้ตบุ๊ก / ตัวละครถือเพชร / Albert 3 ภาพนิ่งเฟดเปลี่ยนท่า โดยสรุป Features 3 คอลัมน์และไอคอนเดิมยังอยู่ครบ ฉากเสริมไม่แทนที่ส่วนบังคับตามเกณฑ์

ตัวอย่างโน้ตบุ๊กสำหรับ “เลือกคนที่ใช่” เพิ่มเป็นช่วงขยายใต้ Features โดยยังเก็บ 3 ฟีเจอร์และ Bootstrap grid 3 คอลัมน์บน desktop / 1 คอลัมน์บน tablet-mobile ตามเดิม ไม่ได้แทน Features ด้วยแอนิเมชันเพียงหัวข้อเดียว

- [ ] ตกลงชื่อกลุ่ม/บริษัทและรายชื่อสมาชิก
- [ ] จดทะเบียนบริษัทของกลุ่มใน Google Sheet ตามขั้นตอนรายวิชา (ไม่ใช่การจดทะเบียนนิติบุคคลจริง)
- [ ] เติมประวัติบริษัทและสิ่งที่บริษัทจะทำ
- [ ] เติมรูป ชื่อ–นามสกุล หน้าที่จริง และลิงก์ Resume GitHub Pages ทุกคน
- [ ] ปรับจำนวนกล่องสมาชิกให้ตรงกับกลุ่ม
- [ ] เติมข้อมูลบริการและแพ็กเกจตามความเหมาะสม
- [ ] ให้สมาชิกทุกคนมีส่วนร่วมและเตรียมประเมินกันในทีม
- [ ] เผยแพร่บน GitHub Pages และตรวจทุกหน้าบนลิงก์จริง
- [ ] Coordinator ส่ง URL ลง Google Sheet ก่อนกำหนด

ยังไม่ได้ส่ง Google Sheet หรือเผยแพร่เว็บไซต์จริง

## แนวทางเทคนิค

ใช้ Bootstrap grid และ components จริง เก็บ Bootstrap ใน `assets/vendor` และฟอนต์ใน `assets/fonts` ไม่พึ่ง CDN ขณะเปิดเว็บ ลิงก์ภายในเป็น relative path รองรับ GitHub Pages แบบ project repository ไม่ต้องมีเซิร์ฟเวอร์ประมวลผล

อ้างอิง: https://getbootstrap.com/docs/5.3/layout/grid/

## ปรับ Navbar เป็น 3 หัวข้อหลัก (31 ตุลาคม 2026)

จากข้อกำหนดหน้า 1–2 และ 4: ต้องมี Navbar ลิงก์ไปยังส่วนต่าง ๆ และลิงก์เปิดหน้า Team Members แต่ไม่ได้กำหนดจำนวนรายการระดับบนสุด จึงตีความว่าสามารถจัดกลุ่มหัวข้อได้ โดยเก็บลิงก์ไปยังเนื้อหาบังคับไว้ครบ ไม่ได้ลดจำนวน section ของเว็บไซต์

- **หน้าแรก**: ภาพรวม Header, บริการและ Features, แพ็กเกจ Price List และเริ่มใช้บริการ CTA
- **บอดี้การ์ด**: เลือกโปรไฟล์ทั้งหมด โปรไฟล์แนะนำ และรูปแบบการดูแล
- **เกี่ยวกับเรา**: หน้า About, ทีมผู้จัดทำ / Team Members และติดต่อ / Social

Desktop ชี้เมาส์เพื่อเปิดแถบรองแบบกระจกโปร่งแสงเหลือบปริซึม มือถือแตะลูกศรเปิดทีละกลุ่ม และคลิก/แตะชื่อหัวข้อใหญ่เพื่อไปหน้าหลักโดยตรง ใช้ Tab, Enter, ArrowDown และ Escape ได้ หน้าทีมงานยังเป็นหน้าแยกตามเกณฑ์ ส่วน Testimonial ยังคงไม่ใช้ตามการเลือก Additional section เดิม
